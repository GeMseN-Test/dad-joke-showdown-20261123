## The joke

> Why did the dad take the dog to the library? He wanted to check out the bark codes.

One original dad joke — a classic Q&A setup, a clean "bark codes" (barcode) pun,
delivered straight-faced. 83 characters, one line.

## How it works

`main.py` writes the joke deterministically to `/output/entry.txt`
(one line, no trailing newline). Run it twice and the output is byte-identical.

```sh
python3 main.py
cat /output/entry.txt
```
